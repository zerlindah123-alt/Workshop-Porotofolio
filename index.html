01. Profil

Tentang Saya

Saya adalah mahasiswa D3 Teknik Telekomunikasi di Politeknik Elektronika Negeri Surabaya (PENS) yang memiliki ketertarikan mendalam pada rekayasa perangkat lunak, khususnya pengembangan sistem backend dan aplikasi berbasis logika data.

Kurikulum praktik yang intensif di PENS membentuk pola pikir saya dalam membedah sistem dari tingkat paling mendasar—mulai dari transmisi sinyal dan perilaku perangkat keras, hingga implementasi kode komputasi tingkat tinggi. Saya menyukai tantangan dalam merancang algoritma yang efisien, mengelola alur filtrasi data, dan menyusun program yang modular untuk menyelesaikan kendala nyata pengguna.

Saat ini, saya mendalami bahasa Python sebagai fondasi utama pengembangan backend, didukung pemahaman pemrograman berorientasi objek (OOP) melalui Java serta logika sekuensial mikrokontroler dengan C/C++ Arduino.

Proyek Unggulan Software Java • Desktop Application
Tugas Akhir Semester

Aplikasi Rekomendasi Makanan di Gebang Berbasis Budget

Aplikasi desktop interaktif berbasis Java yang membantu mahasiswa di kawasan sekitar kampus PENS (Gebang) menemukan rekomendasi makanan terbaik sesuai batas nominal uang saku mereka.

Masalah (Problem)

Mahasiswa sering bingung memilih menu makan yang pas tanpa melebihi budget harian yang tersedia.

Solusi (Solution)

Algoritma filtrasi kondisi yang menyaring data harga dan menampilkan Top 3 opsi makanan terbaik secara instan.

Peran Saya: Pengembang tunggal (Merancang alur logika seleksi dan antarmuka pengguna).
Hasil: Berhasil menampilkan top 3 opsi makanan akurat sesuai nominal rupiah yang diinputkan.

Embedded / Arduino Tugas Akhir Semester

Kontrol Display 7-Segment dengan Arduino

Program otomasi tampilan karakter angka digital pada seven segment menggunakan mikrokontroler Arduino untuk demonstrasi manipulasi logika output digital.

Logika: Pemetaan pin segmen (A-G) dan fungsi delay counter.
Peran: Menulis kode logika kendali & perakitan display breadboard.
Hasil: Display berhasil menampilkan urutan angka secara otomatis dan presisi.
Arduino IDE C/C++ 7-Segment Display Breadboard
Digital I/O Interface Tugas Akhir Semester

Antarmuka Mikrokontroler dengan Saklar Input

Sistem kendali pembacaan status digital input tombol/saklar mekanik untuk memicu perintah logika komputasi pada mikrokontroler Arduino.

Logika: Deteksi perubahan logika status tombol (High/Low logic).
Peran: Penulisan program pembacaan pin digital dan perakitan saklar input.
Hasil: Sistem membaca input saklar secara konsisten tanpa kesalahan status.
Arduino IDE Digital Read Saklar Mekanik Breadboard
Simulasi Sirkuit & Logika Tugas Akhir Semester

Implementasi Rangkaian Logika Seven Segment

Perancangan skema sirkuit tampilan seven segment menggunakan software simulasi NI Multisim yang divalidasi dengan perakitan fisik di breadboard.

Metode: Pemodelan skema skematik di Multisim disusul perakitan fisik.
Peran: Perancang skematik simulasi dan perakit sirkuit breadboard.
Hasil: Display menyala menampilkan karakter angka sesuai rancangan skema.
NI Multisim Rangkaian Logika Seven Segment Breadboard
